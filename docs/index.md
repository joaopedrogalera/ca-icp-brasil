# CA-ICP Brasil

Extrator de certificados do repositório SERPRO.

## O que é?

Este projeto fornece ferramentas para extração e processamento de certificados digitais da Infraestrutura de Chaves Públicas Brasileira (ICP-Brasil) a partir do repositório SERPRO.

## Recursos

- Extração de certificados do repositório SERPRO
- Processamento em lote de certificados
- Análise de informações de certificados ICP-Brasil

## Como usar

```bash
npm install
npm run start
```
